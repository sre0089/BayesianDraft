# Data Schema

This document will define stable internal schemas before live data integrations are added.

Required schema areas:

- Player
- Team
- Game
- WeeklyStats
- SeasonStats
- Projection
- ADP
- Injury
- DraftPick
- Roster
- DraftState
- Recommendation
- SimulationResult
- LeagueConfig
- DataSnapshot

Each schema must document purpose, primary key, foreign keys, required fields, optional fields, data types, validation rules, source fields, versioning, example records, and known limitations.
